# VFX textures

Drawn by `tools/vfx_textures.py` (`py tools/vfx_textures.py <out_dir> --preview`; previews are composited over a dark background). Uploaded to Roblox; the asset ids live in `Client.Vfx.Kit.Textures`. The PNGs aren't stored here (the sandboxed shell can't write into Documents): rerun the script to get them. The beam textures are saved tall because Roblox runs a beam texture's vertical axis along the beam.

| File | Use |
|---|---|
| blood_crescent.png | Blood Blade body: dark wet crescent with hot rim, gloss, flow streaks, drips |
| blood_glow.png | Soft halo along the crescent's outer rim |
| beam_core.png | Light Beam core and glow bands (tileable along the beam) |
| beam_energy.png | Light Beam scrolling energy strands (tileable) |
| glint.png | Four-point glint: charge armed, muzzle flares |
| soft_glow.png | Round soft glow |
